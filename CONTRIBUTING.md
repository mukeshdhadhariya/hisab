# Contributing to Hisab

First off, thank you for considering contributing to **Hisab**! It's people like you that make open source such a great community to learn, inspire, and create.

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please create an issue on GitHub. Include as much detail as possible:
* A clear and descriptive title
* Exact steps to reproduce the issue
* Expected behavior vs. actual behavior
* Screenshots if applicable
* Your environment (OS, Node version, Device/Emulator)

### Suggesting Enhancements
Have an idea for a new feature? We'd love to hear it! Open an issue and use the "Enhancement" label. Please describe:
* What the feature is
* Why it would be useful
* Any potential UI/UX ideas

### Submitting Pull Requests
1. **Fork the repository** and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure your code follows the existing style (run `npm run lint`).
5. Issue that pull request!

## Local Development Setup

To set up the project locally for development, please refer to the **Local Development Setup** section in our `README.md`.

## Coding Guidelines
* We use **React Native** (Expo) and **Node.js**.
* Prefer functional components and React Hooks.
* Ensure no warnings are thrown in the console.
* Keep styling clean and use the global `ThemeContext` for colors.

Thank you for contributing!
